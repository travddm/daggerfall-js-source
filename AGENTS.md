# AGENTS.md

Read [CLAUDE.md](CLAUDE.md) first: it holds the rules for anyone who changes this repository, person or agent. The
documentation starts at [docs/README.md](docs/README.md).

- Standards for new and touched code: [docs/coding-standards.md](docs/coding-standards.md).
- Before a push: `npm run lint`, `npm run types`, `npm run test:changed`, and `npm run format:check`,
  `npm run markdown` and `npm run spell` for the files you changed.
- Tests: [docs/testing/writing-tests.md](docs/testing/writing-tests.md).
